# کیت سازمان ایجنتی رسا
این بسته یک طرح اجرایی قابل توسعه و نمونهٔ تعاملی است، نه ربات آمادهٔ متصل به حساب شما. فایل HTML را آفلاین باز کنید، مراحل را جلو ببرید و تأیید انسانی را آزمایش کنید. JSON نقش‌ها و محدودیت‌ها را مستند می‌کند. پرامپت‌های تألیفی در فایل جداگانه‌اند. برای اجرای واقعی به پیاده‌سازی گردش‌کار، ذخیرهٔ خصوصی کلیدها، قیمت‌گذاری معتبر مدل و بررسی مالک نیاز دارید.
سقف پیشنهادی فعلی رسا: ۵۰ سنت در روز؛ فرمول سناریو جایگزین حسابداری واقعی نیست.
